Plugin one

CustomEnchants

Design your own enchantments in simple YAML files. No coding needed.

Paper 1.21.xPaper 26.2 buildComing soon

Enchantments in YAML

Each enchantment is a short entry: what items it goes on, when it fires and what it does. 14 starter enchantments are included.

Lots of triggers and effects

Fire on attack, defence, mining, bow shots, kills, fishing, elytra flight and more. Effects go from potions and lifesteal to lightning, explosions and summons, with a chance and cooldown per level.

Souls system

Weapons with a Soul Tracker collect souls on every kill. Any enchant level can cost souls to activate, so the strongest ones have to be earned.

Plugin items

White and Black Scrolls, success dusts, slot increasers, rename tags, kill and block counters, Soul Gems, Transmog Scrolls and more, handed out with /ce giveitem.

Enchanter, Tinkerer, Alchemist

Players buy books with XP at the Enchanter, trade enchanted gear for XP at the Tinkerer, and merge two identical books into a higher level at the Alchemist.

Armour sets, kits, mob drops

Full-set bonuses (Lava and Frost sets included), claimable kits with cooldowns and random enchant rolls, and enchant books that drop from mobs.

What an enchantment looks like

lifesteal:
  display: '%group-color%Lifesteal'
  description: 'Steal health from your victims.'
  type: ATTACK          # when it fires
  group: RARE           # rarity, from groups.yml
  applies:
    - ALL_SWORD
  levels:
    '1':
      chance: 12         # % chance to fire
      effects:
        - 'STEAL_HEALTH:1 @Victim'
        - 'PARTICLE:HEART:5 @Self'

Books go on by drag and drop (rolls the book's success chance), in an anvil (costs XP, always works), or as a bonus from the vanilla enchanting table.

How it's set up

  1. Drop the jar in your plugins folder and restart.
  2. It creates enchantments.yml, groups.yml and config.yml for you.
  3. Edit the YAML, then run /ce reload.
  4. Put your license.txt in plugins/CustomEnchants/.

Plugin two

TitansBans

Bans, mutes and warnings that follow a player across your whole network.

Paper 1.20 – 26.xVelocity 4.2.x proxyComing soon

One ban, every server

All your servers share one MySQL database. A ban on any server applies everywhere, checked at the proxy and on every backend.

Follows the player

Punishments are tied to the player's account (UUID), so changing their name doesn't help. /history shows everything, and unbans stay on record.

IP bans and alt alerts

Every login saves the name and IP. /dupeip lists accounts on one IP, and staff get an alert when a banned player's IP-mate logs in.

Templates and warn ladders

/ban Steve #hacking fills in a preset reason and length. Warnings add up: for example 3 warnings can mean a 1-hour mute, automatically.

Staff limits, silent mode

Cap how long junior staff can ban for. Add -s to any command so only staff see the punishment.

Discord webhooks

Every punishment can post a message to a channel on your Discord, so your whole team sees what happened.

Fails safeIf the database can't be reached, TitansBans refuses to run rather than let banned players slip in.

Commands

/ban/tempban/banip/mute/tempmute/kick/warn/unban/unmute/history/dupeip
Planned, not built yet
  • /lockdown: block everyone except staff from joining, for example during a raid.
  • One-server punishments: for example, muted on Survival only.

How it's set up

  1. Put TitansBans in each Paper server's plugins folder.
  2. Running Velocity? Put TitansBansProxy in the proxy's plugins folder.
  3. Create one MySQL database and use the same login in every server's config. Give each server its own server-name.
  4. Add your license.txt and restart.

Only one server? Leave MySQL off and it uses a local SQLite file by itself.

No phone-home

Licence delivery

Your licence is a small signed text file. The plugin checks it on your server, with no internet connection and no licence server that can go down.

You buy

We sign your licence

We make a license.txt with your name and your server's address, and seal it with our private key.

You install

Drop it in

You get your own copy of the plugin plus the licence file. Put license.txt in plugins/<PluginName>/ and restart.

The plugin

It checks itself

Every time the server starts, the plugin checks the seal on the file. All offline: nothing is sent anywhere.

What the file looks like

# TheTitansClan licence - do not edit
version:  1
plugin:   TitansBans
buyer:    Your Name
buyer_id: TC-0001
server:   play.yourserver.net
issued:   2026-10-04
expires:  never
sig:      (signature)

Example values. Re-saving the file or adding comments is fine. Changing any value breaks the seal. Your copy of the plugin also carries your buyer ID, so please don't share it.

If the licence has a problem

TitansBansBans, mutes and the login check keep working. Only the extras switch off: Discord webhooks, templates and the warn ladder.
CustomEnchantsPaid features switch off until the licence is fixed. Items already in players' inventories are left alone, and the server keeps running.

A licence problem never crashes your server, kicks players or deletes anything. And it never lets a banned player back in.

Before you buy

Questions

Which versions do the plugins support?

CustomEnchants: Paper 1.21.x on Java 21 (tested on 1.21.4), plus a separate build for Paper 26.2.

TitansBans: Paper 1.20 to 26.x on Java 17 or newer. The optional proxy plugin needs Velocity 4.2.x on Java 25.

Do I need internet for the licence?
No. The plugin checks the licence file on your own server when it starts. It never calls home, so there's no licence server that can go down and take your server with it.
Can I move to a new server?
Your licence names the server it was made for, and each licence is for one server. If you're moving, open a ticket on our Discord before you switch so we can sort out your licence.
Do I need MySQL or a proxy for TitansBans?
Only if you run more than one server. On a single server, leave MySQL off and TitansBans uses a local SQLite file by itself. For a network, every server points at the same MySQL database, and the Velocity plugin blocks banned players at the proxy.
What if my licence stops working?
Your server keeps running. TitansBans keeps enforcing bans and mutes and only switches off its extras. CustomEnchants switches off paid features but leaves players' items alone. Your server console shows a message saying what's wrong.
